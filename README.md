# Universal Tool v0.5

Небольшая консольная программа на Python с несколькими простыми инструментами.

## Возможности

После запуска программа показывает меню:

1. **PI** — выводит значение π.
2. **Browser** — открывает введённый адрес в браузере по умолчанию.
3. **Password generator** — создаёт пароль, содержащий строчную и заглавную буквы, цифру и специальный символ.

## Требования

- Python 3
- Браузер по умолчанию для функции открытия веб-адреса

Используются только стандартные модули Python: `time`, `webbrowser`, `math`, `random` и `string`. Дополнительные пакеты устанавливать не нужно.

## Запуск

Скачайте репозиторий, откройте терминал в папке с файлом и выполните:

```bash
python "universal tool.py"
```

Если команда `python` не найдена, попробуйте `python3`.

## Примечание

В текущем файле есть опечатка в строке генератора пароля: `string. digits` нужно заменить на `string.digits`, иначе Python выдаст синтаксическую ошибку и программа не запустится.

Программа работает в бесконечном цикле. Чтобы завершить её, нажмите `Ctrl+C` в терминале.
